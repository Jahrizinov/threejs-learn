Quiz Project

Dit was het eerste project dat ik samen met mijn team heb gemaakt: een quiz. Mijn quiz ging over films en series en had een speciaal element: een timer. Zodra de tijd voorbij was, kon je geen vragen meer beantwoorden, wat het extra uitdagend maakte. Tijdens dit project heb ik geleerd hoe je een interactieve applicatie bouwt, hoe je logisch nadenkt over de structuur van de quiz en hoe je samenwerkt in een team om een project van begin tot eind af te ronden. De talen die gebruikten werden: Html en Css voor de structuur en Javascript voor de interactie.
